# 🩻 Multi-Disease Chest X-ray Classifier with Explainable AI

## Overview

This project is a web application that classifies multiple chest diseases from X-ray images using a pretrained DenseNet-121 model and provides visual explanations using Grad-CAM.

## Tech Stack

- Frontend: React
- Backend: FastAPI
- Machine Learning: PyTorch
- Model: DenseNet-121
- Explainability: Grad-CAM
- Deployment: Hugging Face Spaces
